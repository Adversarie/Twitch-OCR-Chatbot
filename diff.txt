+# Path of Exile Client.txt Research
+
+## Log File Location and Basics
+- **PoE 1 & 2 Log Location:** Typically located at `[Install Directory]/logs/Client.txt` (e.g., `C:\Program Files (x86)\Steam\steamapps\common\Path of Exile\logs\Client.txt`). Both PoE 1 and PoE 2 use the same general file and structure.
+- **Log Structure:** 
+  `<Date> <Time> <Internal_ID> <Internal_Hex> [<Log_Level> <Logger> <PID>] : <Message>`
+  *Example:* `2020/10/12 22:39:44 2316728953 ba9 [INFO Client 7124] : You have entered Desert Hideout.`
+
+## Captured Events
+
+### 1. Deaths
+- **Logged?** Yes, but informally. 
+- **Details:** The game client logs a message when the player is slain, often outputting `"You have been slain"` or `"Player died"`. However, it does **not** log damage recaps, the specific source of damage, or your character's level at the time of death. 
+
+### 2. Level Ups
+- **Logged?** Yes. 
+- **Details:** The client logs when a player reaches a new level, usually with the phrase `"is now level X"`.
+
+### 3. Boss Kills
+- **Logged?** Not explicitly. There is no standard structured log for defeating a boss. Some boss encounters might trigger NPC dialogue or quest updates that appear in the log, but parsing this would be highly specific to individual encounters.
+
+### 4. Drops
+- **Logged?** **No.**
+- **Details:** The `Client.txt` file does **not** explicitly log item drops, currency, or high-value loot. Tools that track player wealth typically rely on the official Path of Exile Stash Tab API, not the local text log.
+
+### 5. Chat, Trade, and Areas
+- **Logged?** Yes. Area transitions (e.g., `"You have entered..."`) and all chat/whisper messages are fully logged. This is how many trade companion apps function.
+
+## Regex Parsing Patterns
+
+**Full Line Capture Pattern (Extracts timestamp, PID, and message):**
+```regex
+^(?P<date>\d{4}/\d{2}/\d{2})\s+(?P<time>\d{2}:\d{2}:\d{2})\s+\d+\s+\w+\s+\[\w+\s+\w+\s+(?P<pid>\d+)\]\s+:\s+(?P<message>.*)$
+```
+
+**Specific Event Matching (Applied to the extracted `<message>` string):**
+- **Death:** `(?i)you have been slain|player died`
+- **Level Up:** `(?i)is now level (?P<level>\d+)`
+- **Area Change:** `(?i)you have entered (?P<area>.*)\.`
+```

+# World of Warcraft Log Parsing
+
+World of Warcraft outputs logging to two separate files (which can be toggled in-game via `/combatlog` and `/chatlog`). The files are located in the `_retail_/Logs/` (or `_classic_/Logs/`) directory.
+
+## 1. Combat Log (`WoWCombatLog.txt`)
+The Combat Log captures detailed, structured gameplay data (damage, healing, auras, deaths) in a comma-separated format. It's the best place to reliably parse **Player Deaths**. (Note: Advanced Combat Logging should be enabled in System > Network settings for precise data).
+
+### Player Deaths (`UNIT_DIED`)
+Death events have the `UNIT_DIED` event type. The format of the line is:
+`TIMESTAMP  EVENT_TYPE,SourceGUID,SourceName,SourceFlags,SourceRaidFlags,DestGUID,DestName,DestFlags,DestRaidFlags`
+
+**Raw Example Line:**
+`4/15 20:31:25.123  UNIT_DIED,0000000000000000,nil,0x80000000,0x80000000,Player-970-00000123,Leeroy,0x511,0x0`
+
+**Regex for Parsing Player Deaths:**
+To distinguish player deaths from NPC/pet deaths, we look for `Player-` in the `DestGUID`.
+
+```regex
+^(\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3})\s+UNIT_DIED,.*?,.*?,.*?,.*?,(Player-[^,]+),([^,]+),
+```
+*   **Group 1:** Timestamp
+*   **Group 2:** Target GUID (e.g., `Player-970-00000123`)
+*   **Group 3:** Target Name (e.g., `Leeroy`)
+
+---
+
+## 2. Chat Log (`WoWChatLog.txt`)
+The Chat Log is a plain-text capture of what appears in the user's chat box, prepended with a timestamp. It is the best place to parse **Achievements, Level Ups, and Epic Loot Drops**. 
+
+**Important Note:** The Chat Log formatting is highly dependent on game localization/language, and link codes (like `|H...|h`) are injected for items and achievements.
+
+### Achievement Unlocks
+Achievements are broadcasted in chat with clickable link formatting.
+**Regex:**
+```regex
+^(\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3})\s+(.*?)\s+has earned the achievement\s+\|Hachievement:\d+:.*?\|h\[(.*?)\]\|h
+```
+*(Note: System messages might omit the player name and just say `[Achievement Name] earned.`, but player broadcasts look like above. A generic fallback capturing the `|Hachievement:` block is recommended.)*
+
+### Level Ups
+Level up broadcasts are localized plain-text messages.
+**Regex (English):**
+```regex
+^(\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3})\s+(.*?)\s+has reached level\s+(\d+)!
+```
+
+### Epic Loot Drops
+Loot is logged similarly in the chat file. The game wraps the item in a clickable `|Hitem:...|h` string. To specifically find *Epic* loot, one could theoretically parse the item ID from the string, but standard regex captures any loot matching this pattern.
+
+**Regex (Self / "You receive"):**
+```regex
+^(\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3})\s+You receive loot:\s+\|Hitem:\d+:.*?\|h\[(.*?)\]\|h
+```
+
+**Regex (Other Players):**
+```regex
+^(\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3})\s+(.*?)\s+receives loot:\s+\|Hitem:\d+:.*?\|h\[(.*?)\]\|h
+```
+
+### Important Parser Considerations
+1.  **Buffering:** While `WoWCombatLog.txt` streams relatively quickly, `WoWChatLog.txt` is known to buffer and sometimes only flushes when the user logs out or reloads their UI. If tailing for real-time Twitch alerts, be aware of this limitation.
+2.  **Pipes and Brackets:** The `|H...|h` links contain internal IDs. The regex groups above are designed to capture the human-readable text inside the `[...]` brackets.

+class LogWatcher:
+    def __init__(self, config):
+        self.config = config

+        # WoW Patterns
+        self.wow_death = re.compile(r"^\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3}\s+UNIT_DIED,.*?,.*?,.*?,.*?,(Player-[^,]+),([^,]+),")

+        self.wow_level = re.compile(r"^\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3}\s+(.*?)\s+has reached level\s+(\d+)!")
+        self.wow_loot = re.compile(r"^\d{1,2}\/\d{1,2}\s\d{2}:\d{2}:\d{2}\.\d{3}\s+(You|.*?)\s+(?:receive|receives) loot:\s+\|Hitem:\d+:.*?\|h\[(.*?)\]\|h")
+
+    async def watch(self):
+        """Asynchronous generator yielding (event_id, context) tuples."""
+        files_to_watch = []
+        
+        if self.config.POE_LOG_PATH and os.path.exists(self.config.POE_LOG_PATH):
+            f = open(self.config.POE_LOG_PATH, 'r', encoding='utf-8', errors='replace')
+            f.seek(0, 2) # jump to end
+            files_to_watch.append({'file': f, 'type': 'poe'})
+            logger.info(f"Tailing PoE Log: {self.config.POE_LOG_PATH}")
+            
+        if self.config.WOW_COMBAT_LOG_PATH and os.path.exists(self.config.WOW_COMBAT_LOG_PATH):
+            f = open(self.config.WOW_COMBAT_LOG_PATH, 'r', encoding='utf-8', errors='replace')
+            f.seek(0, 2)
+            files_to_watch.append({'file': f, 'type': 'wow_combat'})
+            logger.info(f"Tailing WoW Combat Log: {self.config.WOW_COMBAT_LOG_PATH}")
+            
+        if self.config.WOW_CHAT_LOG_PATH and os.path.exists(self.config.WOW_CHAT_LOG_PATH):
+            f = open(self.config.WOW_CHAT_LOG_PATH, 'r', encoding='utf-8', errors='replace')
+            f.seek(0, 2)
+            files_to_watch.append({'file': f, 'type': 'wow_chat'})
+            logger.info(f"Tailing WoW Chat Log: {self.config.WOW_CHAT_LOG_PATH}")
+
+        if not files_to_watch:
+            logger.warning("No log files configured or found. LogWatcher is idle.")
+            while True:
+                await asyncio.sleep(60) # Just sleep indefinitely to not break the app runner
+
+        try:
+            while True:
+                for watcher in files_to_watch:
+                    line = watcher['file'].readline()
+                    if not line:
+                        continue
+

+                        yield event

+    def _parse_line(self, line, log_type):

+                
+            area_match = self.poe_area.search(msg)
+            if area_match:
+                return ("poe_area_change", area_match.group(1))
+                
+        elif log_type == 'wow_combat':
+            death_match = self.wow_death.match(line)
+            if death_match:
+                return ("wow_death", f"{death_match.group(2)} died")
+                
+        elif log_type == 'wow_chat':
+            achiev_match = self.wow_achiev.match(line)
+            if achiev_match:
+                return ("wow_achievement", f"{achiev_match.group(1)} earned {achiev_match.group(2)}")
+                
+            lvl_match = self.wow_level.match(line)
+            if lvl_match:
+                return ("wow_level_up", f"{lvl_match.group(1)} reached level {lvl_match.group(2)}")
+                
+            loot_match = self.wow_loot.match(line)
+            if loot_match:
+                return ("wow_loot", f"{loot_match.group(1)} looted {loot_match.group(2)}")
+                
+        return None
