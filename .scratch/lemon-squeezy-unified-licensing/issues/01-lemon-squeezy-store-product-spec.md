## Question

How should the Lemon Squeezy store, subscription products, variants, and license key generation settings (2 activation limits, renewal behavior, product ID guards) be structured in the Lemon Squeezy dashboard, and what configuration variables (`LEMON_SQUEEZY_STORE_ID`, `LEMON_SQUEEZY_PRODUCT_ID`, `LEMON_SQUEEZY_CHECKOUT_URL`) are required for the client applications?

## Answer

### 1. Lemon Squeezy Store & Product Setup

Configure a single Lemon Squeezy store serving both software applications:

1. **Product: Twitch OCR Chatbot**
   - **Type**: Subscription (Recurring).
   - **Billing Intervals**: Monthly ($15/mo) and Annual ($144/yr).
   - **License Key Toggle**: Enabled.
   - **Activation Limit**: `2` (covers streamer gaming PC + dedicated stream PC / laptop).
   - **License Key Format**: Standard UUIDv4 generated by Lemon Squeezy.

2. **Product: Picture Perfect**
   - **Type**: Subscription (Recurring).
   - **Billing Intervals**: Creator Monthly ($12/mo) and Studio Annual ($110/yr).
   - **License Key Toggle**: Enabled.
   - **Activation Limit**: `2` (covers studio editing workstation + field laptop).
   - **License Key Format**: Standard UUIDv4 generated by Lemon Squeezy.

### 2. Client Security Guard (Cross-Product Validation)

Because Lemon Squeezy's License API is public, clients must guard against customers using a valid license key from one product to activate another:
* Client checks `res.meta.store_id === EXPECTED_STORE_ID`.
* Client checks `res.meta.product_id === EXPECTED_PRODUCT_ID`.
If mismatched, client rejects activation with `"License key does not belong to this application."`

### 3. Client Environment Variables Specification

* **Twitch OCR Chatbot** (`.env`):
  ```ini
  LEMON_SQUEEZY_STORE_ID="81234"
  LEMON_SQUEEZY_PRODUCT_ID="45100"
  LEMON_SQUEEZY_CHECKOUT_URL="https://yourstore.lemonsqueezy.com/checkout/buy/<variant_id>"
  LEMON_SQUEEZY_LICENSE_KEY=""
  ```

* **Picture Perfect** (`.env` / build config):
  ```ini
  VITE_LEMON_SQUEEZY_STORE_ID="81234"
  VITE_LEMON_SQUEEZY_PRODUCT_ID="45200"
  VITE_LEMON_SQUEEZY_CHECKOUT_URL="https://yourstore.lemonsqueezy.com/checkout/buy/<variant_id>"
  ```

### 4. Activation Limit Reached (2 Seats) Workflow

When `/v1/licenses/activate` returns `HTTP 200` with `"activated": false` and `"error": "This license key has reached the activation limit."`, the client UI must:
1. Explain that both available machine seats are currently occupied.
2. Provide a 1-click link to the customer's self-service portal (`https://app.lemonsqueezy.com/my-orders`) where they can release previous device activations.
